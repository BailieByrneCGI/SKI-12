# Case results

Each complaint has a stable `CASE-N/` folder containing its latest `report.md`, `findings.json`, filtered form, reviewer draft, audit, and Hermes evidence. [index.md](index.md) lists the cases. A model confidence appears only after a valid Hermes assessment; retrieval-only reports show `pending Hermes` and a numeric rule-match score. `archive/legacy-runs` preserves the older timestamped output. `archive/previous-build` preserves the original generated build from before the folder redesign.

`Analytics/` is generated by `Tools/run_r_analysis.ps1`. It contains a text-free findings export, aggregate tables, charts, and a summary. Suggested actions remain proposals until a reviewer records a separate decision.
